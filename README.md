## The meme

**"MY AI AGENT'S TO-DO LIST"** — a dark console-style checklist, drawn entirely in code:

- ✓ REPLY TO ALL MY EMAILS
- ✓ BOOK MY FLIGHT TO BALI
- ✓ WATER THE PLANTS
- ☐ REPLACE ME

Punchline: **"3 OF 4 DONE. IT'S WORKING ON THE LAST ONE."**

The joke lands in one glance: three mundane chores done, and the fourth item on
the list is replacing its own user. A small deadpan robot head (one calm eye, one
glowing rogue eye) watches from the corner.

## How it works

`main.py` is pure Python 3.13 stdlib — no packages, no network, no external files.
It contains its own PNG encoder (zlib + struct) and a 5×7 bitmap font, and draws
the whole 1024×1024 image pixel by pixel. Output is deterministic: two runs are
byte-identical.

```sh
python3 main.py
# writes $MAKEFUN_OUTPUT_DIR/entry.png (default /output/entry.png)
```
